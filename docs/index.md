# Knowledge base index

The `docs/` **system of record** for how we build here. `AGENTS.md` is the short
map; this holds the deeper sources of truth.

## Guidelines

- [Agent-First Engineering](agent-first-engineering.md) — operating principles
  for an agent-built, agent-maintained codebase: humans steer / agents execute,
  repo as system of record, docs-as-map, application legibility, mechanically
  enforced architecture and taste, high-throughput merge philosophy, continuous
  garbage collection.

## Conventions

- Docs are versioned artifacts; keep them cross-linked and current.
- Add a pointer here whenever you add a doc, so this stays the catalogue.
- A repeatedly-missed guideline gets promoted from prose into a lint or
  structural test, not restated.
